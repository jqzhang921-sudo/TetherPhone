# TetherPhone

一部住着 AI 的小手机。桌面、图标、锁屏、开 app 的动效都仿真机；每个入口背后
是一件它会做的事——聊天、动态、日记、信、记忆、人设。

## 跑起来

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>。

**用手机看**：dev 脚本已经 `-H 0.0.0.0`，同一个 WiFi 下手机浏览器直接开
`http://<电脑的局域网IP>:3000`。iPhone 上「添加到主屏幕」之后是全屏的，
没有浏览器地址栏，和一个真 App 分不出来。

## 先填 API

第一次进去要在 **设置 → 模型** 里填自己的 API：地址 + key + 模型名。
任何 OpenAI 兼容的接口都行（DeepSeek、OpenAI、各种中转）。

key **只存在这台设备的浏览器里**（localStorage），不上传、不进仓库。
调模型时经本站的 `/api/chat` 服务端中转——不是为了拿你的 key，是因为
浏览器直连绝大多数模型接口会被 CORS 挡下，而且报错长得像网络抽风、
不像配置问题，很难查。

|---|---|
| ✅ 壳 | 锁屏（上滑解锁）、状态栏、时钟组件、图标网格、Dock、开 app 的缩放动效、home 条上滑退出 |
| ✅ 玻璃 | 深浅两套材质，跟着壁纸走；五张内置壁纸 |
| ✅ 地基 | **联系人穿进所有表**、IndexedDB、导出/恢复备份 |
| ✅ 聊天 | 会话列表 → 聊天室，流式输出，点头像看资料 |
| ✅ 通讯录 | 建/改/删联系人：头像、备注、虚拟号码、签名、人设、单独的模型 |
| ✅ 设置 | 接口、你自己的资料、壁纸、备份、清空 |
| ✅ 日记 | 交换日记：双方都能写、私密/公开、公开会在聊天里落一行、横线/方格/空白 × 四种纸色、手写体 |
| ⬜ 其余六个入口 | 图标占着位子，点开是「还没做」的空态 |

**没画假界面是故意的**：假的列表和假数据会让人分不清「还没做」和「坏了」，
自己看久了也会当它已经完成。

规划和为什么这么排，见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 目录

```
app/
  page.tsx            入口，只负责把 <Phone /> 摆在屏幕中间
  globals.css         玻璃系统 + 设计 token（看这个文件顶部的注释）
  api/chat/route.ts   模型接口中转 + SSE 透传
components/
  phone/              壳：设备框、锁屏、桌面、状态栏、app 窗口、图标、资料卡
  apps/               各个入口的内容
tools/
  slice-font.py       把中文字体切成 unicode-range 分片。换字体重跑它
  fonts/              字体源文件（不对外服务）
lib/
  db/idb.ts           IndexedDB 层。除 contacts 外每张表都按 contactId 建了索引
  os/contacts.ts      联系人 = 角色。人设/模型/记忆都挂这儿，不在全局设置里
  os/backup.ts        导出/恢复整机数据
  apps/registry.tsx   app 注册表。加一个入口 = 在这里加一条
  os/                 壁纸、设置
  chat/               聊天记录存取（按联系人分段）
```

加一个新入口：在 `lib/apps/registry.tsx` 加一条，然后在
`components/phone/phone.tsx` 的分支里接上组件。`ready` 不写就是占位态。

## 几条不该丢的规矩

代码里有注释写明白了为什么，这里只列标题：

- **玻璃**：浅底靠阴影不靠描边，深底不画阴影靠一道暖白亮边。两边同一套 =
  浅底白描白等于没画、暗底黑影看不见。
- **玻璃**：高 alpha + 小模糊是一对。靠大模糊撑可读性会让背景糊成一片灰。
- **颜色**：一律走 OKLab。HSL 的饱和度不是感知量——同一个数值在不同色相上
  不是同一种「花」，接近黑的像素上它还是个噪声放大器。
- **SSE**：解析必须跨分片缓冲。按分片 `split("\n")` 会把被切开的那行两半都丢，
  症状是长回复零星掉字，不是尾部截断，特别难认。
- **人设**：只给名字，不挂形容词。挂了「贴心的助手」这类标签，模型就去演那个词。
- **字体分片**：按码位顺序均分是错的——常用汉字散落在整个 U+4E00–U+9FA5，
  一页会打到二三十片，等于整包下载。要按 GB2312 区位分常用度分层。
- **日记的「公开」是动作不是开关**：公开时在聊天里落一行，这件事才有时间、
  有来由。只做个开关，翻过去就没了。

## 一条必须知道的

**iPhone 上，Safari 会把七天没打开过的网站数据清掉。** 日记、相册、聊天记录
全在本地，等于全没。**「添加到主屏幕」之后不受这条限制**——所以那一步不是
锦上添花。不管加没加，设置里的「导出备份」定期点一下都不亏。

## 做不到的事

这是网页，所以**没有后台**——它不会在你没打开的时候自己醒过来说话。
国内安卓的浏览器推送要过 FCM，收不到；iOS 加到主屏幕后倒是能收
（走苹果的 APNs），但那需要一个真后端：存推送订阅、定时任务、在服务端调模型。
路是通的，只是还没修。
